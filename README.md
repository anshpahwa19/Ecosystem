# Bloom Digital Ecosystem — stakeholder proposal

- `Bloom-Digital-Ecosystem-Proposal.html` — the proposal as one standalone file. Open it in a browser.
- `src/proposal.html` — source. Logos live in `src/assets/` and are inlined by the build.
- `dist/bloom-digital-ecosystem.html` — the build published to the Claude artifact.

Rebuild after editing the source:

```sh
python3 build.py
```

Navigate with the arrow keys, the chapter menu at the top, or by swiping. Every figure links to its source; the full list is in the Sources drawer and the appendix.
